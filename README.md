# Student Grade Calculator

## 📌 Project Description

A Java-based Student Grade Calculator that accepts marks for multiple subjects, validates the input, calculates total marks and percentage, and determines the student's grade.

This project is developed as part of the Java Programming Internship Task 2.

## 🎯 Objective

The main objective of this project is to practice:

- Variables
- Arrays
- Loops
- Conditional statements
- Input validation
- Basic calculations
- Java programming concepts

## 🛠️ Technologies Used

- Java
- JDK
- Eclipse IDE

## ✨ Features

- Accepts marks for multiple subjects
- Stores marks using an array
- Validates marks between 0 and 100
- Calculates total marks
- Calculates percentage
- Determines student grade
- Displays the final grade report

## 📊 Grade Criteria

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A |
| 80 - 89    | B |
| 70 - 79    | C |
| 60 - 69    | D |
| 50 - 59    | E |
| Below 50   | F |

## 🚀 How to Run

1. Install Java JDK.
2. Open Eclipse IDE.
3. Create or import the project.
4. Open `StudentGradeCalculator.java`.
5. Run the program as a Java Application.
6. Enter marks for all five subjects.
7. The program will display the total, percentage, and grade.
